# Stream Launcher Icons

Three monochrome prompt glyphs for the stream picker: U+E900 Twitch,
U+E901 YouTube, U+E902 Rumble. Fuzzel uses JetBrains Mono for normal text.

SVG sources are from Simple Icons (CC0-1.0):
https://github.com/simple-icons/simple-icons
Brand names and logos remain trademarks of their respective owners.

Rebuild with `python build.py` in an environment with fonttools installed.
Install this directory under ~/.local/share/fonts and run fc-cache -f.
